# Security Policy / セキュリティ方針

## サポート対象

最新の公開Releaseと現在の`main`ブランチを対象に、セキュリティ修正を提供します。

## 脆弱性の報告

GitHubリポジトリのSecurityページからPrivate Vulnerability Reportingを使用してください。利用できない場合、公開Issueには脆弱性の詳細を書かず、非公開の連絡方法を求める文だけを投稿してください。

公開Issueへ脆弱性の詳細、ローカル絶対パス、非公開画像、プリセット、診断情報、認証情報やその他の秘密情報を投稿しないでください。

報告には、拡張のバージョン、ホスト名とバージョンまたはコミット、OS、再現手順、個人情報と絶対パスをマスキングした診断レポートを含めてください。

## Supported versions

Security fixes are provided for the latest published release and the current `main` branch.

## Reporting a vulnerability

Use GitHub Private Vulnerability Reporting from the repository Security page. If it is unavailable, post only a request for a private contact method in a public Issue; do not disclose vulnerability details there.

Do not post vulnerability details, absolute local paths, private images, presets, diagnostics, credentials, or other secrets in a public Issue.

Include the extension version, host name and version or commit, OS, reproduction steps, and a diagnostic report with personal information and absolute paths redacted.
