# Comic Panel Editor 0.7.9 クロップ・整列・Canvas追従 テストガイド

## 1. 一枚画像: 縦長→横長
1. 一枚画像モードで縦長画像を読み込みます。
2. 画像をドロップまたは「画像を変更」で横長画像へ差し替えます。
3. 他の編集レイヤーが無い場合、Canvas幅・高さと縦横比が横長画像へ自動追従することを確認します。
4. 横長→縦長でも同様に確認します。

## 2. 編集済みCanvasの画像差し替え
1. 一枚画像へテキストまたは吹き出しを1個追加します。
2. 縦横比の異なる画像へ差し替えます。
3. 「画像サイズに合わせる / 現在のキャンバスを維持」の確認が出ることを確認します。
4. OKではCanvasと既存レイヤーが相対位置を保ってスケールされ、キャンセルでは現在Canvasサイズが維持されることを確認します。

## 3. Propertiesからクロップ
1. 画像レイヤーを1枚選択します。
2. Propertiesに「クロップを編集」「クロップをリセット」が表示されることを確認します。
3. 「クロップを編集」でクロップ枠とCanvas上の「確定 / キャンセル / リセット」が表示されることを確認します。

## 4. クロップへのショートカット入口
- 選択画像をダブルクリックしてクロップモードへ入れること。
- 選択画像が1枚のときCキーでも入れること。
- 入力欄へ文字入力中はCキーが奪われないこと。

## 5. クロップ操作
- 四隅・辺のハンドルで表示範囲を狭められること。
- クロップ枠内をドラッグすると、枠を維持したまま元画像の使用位置を移動できること。
- 元画像ファイル自体は変更されず、クロップ後も「クロップをリセット」で全体へ戻せること。

## 6. 確定 / キャンセル / リセット
- Enterまたは「確定」で変更が確定すること。
- Escまたは「キャンセル」でクロップ開始時の状態へ戻ること。
- 「リセット」で元画像全体へ戻ること。

## 7. クロップ Undo / Redo
1. クロップを確定します。
2. Ctrl+Zでクロップ前へ戻ることを確認します。
3. Ctrl+YまたはRedoでクロップ状態へ戻ることを確認します。

## 8. 2オブジェクト整列
1. テキスト、吹き出し、SFX、スタンプ、画像などから2個を複数選択します。
2. Propertiesが複数選択表示へ切り替わり、横4・縦4アイコンが表示されることを確認します。
3. 左端 / 水平中央 / 右端 / 上端 / 垂直中央 / 下端が動作することを確認します。
4. 2個選択時は水平分布 / 垂直分布だけ無効になることを確認します。

## 9. 3オブジェクト分布
1. 3個以上を複数選択します。
2. 水平分布、垂直分布が有効になることを確認します。
3. 1回の操作をCtrl+Zで全オブジェクト同時に元位置へ戻せることを確認します。

## 10. 整列基準
- 「選択オブジェクト」: 選択群の外周を基準に整列すること。
- 「ページ」: ページ全体の端/中央を基準に整列すること。
- 「コマ」: 全選択オブジェクトが同一コマ所属の場合だけ選択でき、そのコマを基準に整列すること。
- 異なるコマやページ要素が混在した場合、「コマ」が無効になること。

## 11. 回転画像のクロップ
安全なクロップ幾何を優先する0.7.9では、回転角度が0°以外の画像はクロップ編集を開始しないことを確認します。0°へ戻すと編集できます。
