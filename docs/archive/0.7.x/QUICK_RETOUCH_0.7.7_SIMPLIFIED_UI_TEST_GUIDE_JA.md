# Quick Retouch 0.7.7 選択UI・入力UI整理 テストガイド

1. Quick Retouch上部の「画像を変更」を押し、画像候補・ドラッグ＆ドロップ・「ファイルを選択」が展開されることを確認します。
2. 選択範囲パネルに「保護範囲」が存在しないことを確認します。
3. 投げ縄 → 矩形 → 自動選択（魔法の杖） → 色域選択の順になっていることを確認します。
4. Q または「クイックマスク」で赤いオーバーレイが選択外に表示され、ブラシで追加・消しゴムで削除できることを確認します。
5. 目などを投げ縄選択して「反転」し H/S を追加し、反転後の範囲だけに調整が適用されることを確認します。
6. ペイント1／ベース画像を選択したとき Properties パネルが閉じ、レイヤーパネル上部の不透明度が利用できることを確認します。
7. H/Sを選択したとき Properties が表示され、色相・彩度・明度のスライダーに色のガイドが表示されることを確認します。
8. H/Sの「対象色を詳細調整」が初期状態で折りたたまれていることを確認します。
9. Ctrl+Dで現在選択と色域候補が解除され、二重のグローバルマスクが残らないことを確認します。
10. ブラシ、消しゴム、選択、反転、レイヤー追加、H/S変更をUndo/Redoできることを確認します。
