# Quick Retouch 0.7.4 キャッシュ・カーソル・キャンバス移動 テストガイド

対象: Quick Retouch 0.7.3 のカーソルが読み込まれない問題と、全体表示中のキャンバス移動を修正した版。

## 確認項目

1. ブラシを選び、キャンバス上へ移動します。円の直径が上部のブラシサイズと一致し、中央に小さい「＋」が表示されることを確認します。
2. 左ドラッグ中だけ円内が薄い赤になることを確認します。
3. 消しゴムでは同じ直径の円と中央の「−」、薄い水色系の描画中表示になることを確認します。
4. 右ボタンを押したまま左右へ動かし、円と `80 px` 形式のHUDがリアルタイムで変わること、右クリックメニューが出ないことを確認します。
5. ブラシまたは消しゴムで Alt を押し、スポイトカーソルへ一時切替され、クリック位置の色が描画色へ入ることを確認します。Altを離すと元のカーソルへ戻ります。
6. スポイト、手のひら、ズーム、自動選択でそれぞれ専用カーソルになることを確認します。ズームは Alt 中に縮小カーソルになります。
7. 自動選択・矩形・投げ縄で Shift、Alt、Shift+Alt を押し、上部の「追加」「削除」「共通」ボタンが一時的に強調されることを確認します。
8. 色域選択で通常、Shift、Alt の順に、基準スポイト、＋スポイト、−スポイトへ変化することを確認します。候補範囲は青紫、確定後の通常選択は青系で表示されます。
9. 選択範囲パネルを「非表示」にしてから選択を追加・置換し、表示は非表示のまま、選択データが残ることを確認します。
10. 画像全体が作業領域内に収まっている状態でも、マウス中ボタンドラッグ、手のひらツール、Space＋左ドラッグでキャンバス位置を移動できることを確認します。
11. 「全体表示」を押すとキャンバス位置が中央へ戻ることを確認します。
12. ウィンドウ見出しに `Quick Retouch 0.7.4` と表示されることを確認します。表示されない場合は古いProject Editorウィンドウを閉じ、Forge Neoを再起動して `Ctrl+F5` を実行します。
13. Undo/Redo、ホイールズーム、PNG適用が従来どおり動くことを確認します。

元画像はロックされた非破壊の基準画像です。Quick Retouch内のレイヤーは適用時にPNGへ統合されます。
