# Quick Retouch 0.7.6 履歴・選択・開始時復元 テストガイド

1. ベース画像を消しゴムで消し、Undoで戻り、Redoで再度消えることを確認します。
2. 投げ縄・自動選択・色域選択を作成し、Undo / Redoで選択マスクが戻ることを確認します。
3. 色域候補の紫マスク表示中にEscを押し、候補だけ消えて既存選択が残ることを確認します。
4. 色域候補または確定選択がある状態でCtrl+Dを押し、青・紫の表示が消えて「選択範囲なし」になることを確認します。保護範囲の赤は残ります。
5. 目を投げ縄選択して反転し、H/Sを追加します。調整レイヤーマスクが「目は黒、目以外は白」になり、目以外だけが変化することを確認します。
6. 保護範囲を追加した場合は、調整マスクから保護部分が除外されることを確認します。
7. レイヤー追加、削除、複製、表示、ロック、H/Sスライダー変更をUndo / Redoできることを確認します。
8. 「開始時に戻す」を押して確認後、画像・レイヤー・選択・保護・ズーム・Canvas位置・比較が開始時へ戻ることを確認します。
9. リセット直後にUndoを押し、リセット前の編集状態へ戻ることを確認します。
10. 「編集前を表示（長押し）」、左右分割、上下分割を確認します。
