## 背景削除

［背景削除を開く］から、標準の **InSPyReNet**（約377 MiB）とアニメ向けの **isnet-anime**（約168 MiB）を選べます。未取得のモデルだけ、初回に確認してダウンロードします。すでに取得したisnet-animeも引き続き使えます。

方式を切り替えると前の結果をクリアし、新しい切り抜きができると［適用］できます。更新後はForge Neoを再起動してください。

## Background removal

Open **Background Removal** to choose **InSPyReNet** (default, about 377 MiB) or **isnet-anime** (about 168 MiB). The editor asks before downloading a missing model and reuses either model on subsequent runs, including existing isnet-anime downloads.

Switching models clears the old preview. **Apply** becomes available when the selected model finishes. Restart Forge Neo after updating the extension.
