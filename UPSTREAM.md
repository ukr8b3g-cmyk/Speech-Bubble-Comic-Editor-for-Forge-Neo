# Upstream and Port Relationship

The editor and Pillow renderer originated in [Speech-Bubble-Layer](https://github.com/ukr8b3g-cmyk/Speech-Bubble-Layer). Both that project and this repository are maintained by the same author.

This repository is an independent port for WebUI ReForge / Forge Neo. It does not import, redistribute, or require ComfyUI at runtime. The host-specific adapter, local API routes, storage and export handling, Settings integration, and txt2img/img2img launcher UI are maintained here.
